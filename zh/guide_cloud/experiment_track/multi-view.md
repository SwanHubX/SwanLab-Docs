# 多视图

在同一个项目中创建多个独立看板，每个视图都可以单独保存自己的筛选、分组和图表布局，互不影响。

多视图基于新版看板架构。**升级方式**：打开需要升级的 `项目/Project`，点击**右上角**的 **「升级至新版看板」**，即可完成看板升级；通过网页端或新版 SDK 创建的新项目，将自动使用多视图看板，无需手动升级。

**📊 旧项目升级新版看板**：
<img src="https://swanlab-docs-1301372061.cos.ap-beijing.myqcloud.com/assets/images/20260720174505317.png"/>

::: warning 升级前请确认

- ⚠️ 注意：
  - 升级耗时与项目下的实验数量和图表数量有关，请耐心等待
  - 正在进行中的实验无法升级
  - **升级后无法回退到旧版看板**，请务必确认！

**💥 破坏性更新**：

- 升级为新版看板后，需将 SDK 更新至 `v0.9.0+`，才能新建实验、续传实验并上报指标
- 未升级新版看板的项目，仍可使用 `v0.9.0` 之前的 SDK 正常上报指标、创建实验；但 `v0.9.0+` 的 SDK 无法向旧版看板的项目上报指标或创建实验
- 旧版看板将于 **2026 年 10 月 1 日** 后停止维护，建议尽早升级
  :::

## 什么是多视图

训练调参时，你可能既想盯着 loss 曲线的每一丝波动，又想对比十几个实验的最终指标，还想单独整理一份汇报用的结果图表 —— 但这些图表全堆在一个看板里，翻来翻去很快就乱了。

多视图就是为了解决这个问题：**一个项目，多个看板**。你可以按分析场景创建不同的视图，每个视图记住自己的图表配置，切换视图即可一键切换分析视角。

<img src="https://swanlab-docs-1301372061.cos.ap-beijing.myqcloud.com/assets/images/20260820114444509.png"/>

**多视图能帮你：**

- **满足不同分析需求**：分别创建「实验监控」「模型对比」「结果复现」等视图，各司其职
- **快速切换分析场景**：无需反复调整筛选和布局，切换视图即可看到对应内容
- **避免配置互相干扰**：修改当前视图，不会影响其他视图中已整理好的内容
- **提升团队协作效率**：减少多人调整看板时的冲突，保持分析环境稳定

## 默认视图与自定义视图

创建视图时，可以根据需要选择两种类型：

- **默认视图**：自动渲染实验中记录的所有指标图表，适合快速验证、需要全面查看数据的阶段
- **自定义视图**：从空白画布开始，由你手动挑选并配置关心的指标图表，适合指标过多、需要聚焦核心数据对比的调参阶段

<video controls src="https://swanlab-docs-1301372061.cos.ap-beijing.myqcloud.com/assets/videos/01-demo.mp4"></video>

::: warning 注意
新建的自定义视图是一张空白画布，图表需要你手动添加。
:::

## 个人视图与公共视图

视图支持两种可见范围，按个人使用或团队协作的需求灵活选择：

- **个人视图**：只有你自己可见，放心大胆地按个人习惯整理
- **公共视图**：项目内所有协作者可见，适合作为团队统一的对齐看板

<video controls src="https://swanlab-docs-1301372061.cos.ap-beijing.myqcloud.com/assets/videos/02-pub-pri.mp4"></video>

## 管理视图

一个项目可以创建多个视图，并且支持便捷的视图管理操作：

- **调整顺序**：拖拽排序，把常用的视图放在顺手的位置
- **编辑名称**：随时重命名，让视图用途一目了然
- **置顶视图**：将最重要的视图固定在最前
- **复制视图**：基于已有视图快速创建一个副本，在其基础上微调

<video controls src="https://swanlab-docs-1301372061.cos.ap-beijing.myqcloud.com/assets/videos/03-self-def.mp4"></video>

## 图表布局同步

在同一视图内，**多实验对比图表**与**单实验图表**的布局是双向联动的 —— 对图表和分组的任何调整都会在两者之间同步，实现「一处修改，全域生效」，让不同维度下的查看体验保持一致。
